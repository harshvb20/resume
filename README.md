# Manikandan Madhu — Résumé

Permanent résumé link: **https://harshvb20.github.io/resume/**

The QR code points to this permanent link. The page opens `resume.pdf` automatically. Replace that PDF whenever your résumé changes; the printed QR code will still work.

## Files

- `index.html` — opens the current résumé PDF.
- `resume.pdf` — the current résumé, with a fixed filename.
- `resume-qr.png` — high-resolution QR code for sharing and printing.
- `resume-qr.svg` — vector QR code that stays sharp at any size.
- `.nojekyll` — serves these files directly through GitHub Pages.

## First-time publishing

1. Sign in to GitHub as **harshvb20**.
2. Create a **public** repository named **resume**.
3. Upload the contents of this folder to the repository's root, including `index.html` and `resume.pdf`. The files should be directly in the repository, rather than inside another folder.
4. In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/(root)**, and click **Save**.
5. Wait for GitHub Pages to finish deploying, then open https://harshvb20.github.io/resume/ and scan the QR code with your phone.

## Update the résumé without changing the QR code

1. Export your updated résumé as a PDF and name the upload copy **resume.pdf**.
2. Open https://github.com/harshvb20/resume and select the **main** branch.
3. Click **Add file → Upload files** and upload the new `resume.pdf` to the repository root, replacing the existing file.
4. Click **Commit changes**. GitHub Pages will deploy the update automatically.
5. Allow a few minutes for deployment and caching, then open the permanent link to check the updated PDF. Updates can take up to 10 minutes to appear.

Keep the GitHub username, repository name (`resume`), and Pages URL the same. You can continue using every existing copy of the QR code; there is no QR subscription or renewal required.
